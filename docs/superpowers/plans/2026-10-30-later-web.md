# LATER (web version) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the web version of LATER: the reference mockup turned into a standalone, itch.io-ready browser game that looks and plays exactly like it.

**Architecture:** Plain HTML/CSS/JavaScript ES modules in `web/later/`, with no build step and no dependencies. Game logic (data, rules, the round simulation) is DOM-free and tested with Node's built-in test runner. Rendering, sound and the ending are ported from the mockup and checked by a headless-Chrome smoke script. The Unity version (separate plan, later) reads the same `data.js` values.

**Tech Stack:** HTML, CSS, JavaScript (ES2022 modules), Web Audio, Web Animations API, Node 26 `node --test`, headless Google Chrome, Python 3 `http.server` (test server only), `zip`.

**Spec:** `docs/missed-calls-design.md`. **Visual and behavioural reference:** `docs/reference/later-mockup.html`. The user's instruction: "design it like the showcase". When a task says "port X from the mockup", copy that function's behaviour and look exactly, changing only what the task names.

## Global Constraints

- Game area 960×540, scaled to fit the window, letterboxed, centred.
- Exactly 20.0 s of play from the first frame to "TIME!". All pills off screen by 17 s.
- 14 calls, 29 pills, 8 lanes at y = 54 + 62·i, the schedule and all text copied verbatim from the spec's tables and appendix (they live in `data.js`).
- No voices during play. No music. Sound cuts to silence at "TIME!".
- Colours: answer green `#34C759`, decline red `#FF3B30` (during play only), ink `#141414`, paper from `rgb(253,220,172)` to `rgb(146,158,172)` driven by missed pills ÷ 29. Pills have a 2 px ink border (`box-sizing: border-box`, so pill sizes don't change).
- Fonts bundled locally (no runtime Google Fonts): Anton, Archivo Black, Newsreader Italic.
- Browser tab title and title screen: **LATER**.
- No glows, gradients or bouncy effects.
- A careful dodger must never be forced to touch a call.
- Works from a zip uploaded to itch.io (relative paths only).

## Review Focus

- **Restarting mid-ending** (PLAY AGAIN, or clicks during the flights): every pending timer and animation from the old ending must be cancelled, so nothing from it appears in the new round. Test in Task 5.
- **A long frame or a hidden tab** (slow device, switching tabs): a pill must not tunnel through the player or skip a pass, and play must pause while the tab is hidden. Tests in Task 3 (frame hitch) and Task 6 (hidden tab).
- **No audio available** (AudioContext missing or blocked): the game runs silently with no errors. Test in Task 4.
- **Touch** (finger covering the moon, double-tap zoom, page scroll): play is usable and the page never zooms or scrolls. Test in Task 6.
- **Clicking twice fast on TURN BACK TIME or the Messages card**: one response, one sheet, nothing stacks. Test in Task 5.

### Task 3: The round simulation

**Files:**
- Create: `web/later/src/round.js`, `web/later/tests/bots.js`, `web/later/tests/round.test.js`

**Interfaces:**
- Consumes: `data.js`, `rules.capsuleDist`.
- Produces (`src/round.js`):
  - `createRound(pillW = DEFAULT_PILL_W): Round`
  - `stepRound(round: Round, dt: number, input: { target: {x,y}, keys: {x: -1|0|1, y: -1|0|1} }): RoundEvent[]`
  - `Round` fields read by later tasks: `t, me: {x,y}, tilt, pills: Pill[]` (live only), `calls: CallState[], score, combo, best, closeN, missed, dodged, hits, bonus, paperK, over`
  - `Pill = { id, ci, who, x, y, w, h, vx, vy, minD, passed, gain, seed }`. `CallState` = a `CALLS` row plus `{ spawned, alive, answered, missedN, band, start, gap }`.
  - `RoundEvent` is one of `{type:"date", date}` (a call starting, or a quiet date), `{type:"spawn", pill}`, `{type:"pass", pill, close}`, `{type:"unpass", pill}`, `{type:"hit", pill}`, `{type:"remove", pill}` (gone from play: answered with its call, or off screen), `{type:"time"}` (exactly once, when `t` reaches 20)
- Produces (`tests/bots.js`, also loaded by the browser harness):
  - `dodgeTarget(round, x: number): {x,y}`: a careful dodger, ported from the logic below
  - `chaseTarget(round, wants: (pill) => boolean = () => true): {x,y}`: the centre of the leftmost wanted pill on screen, or `{x:200, y:300}` if there is none

- [ ] **Step 1: Write the failing tests** `tests/round.test.js`, with a helper `play(bot, dt = 1/60)` that creates a round, steps it until `over`, applies `bot(round)` as `input.target` each step, and records hits, every event, the largest pairwise pill overlap (rectangles, ignoring overlaps under 4 px in either direction) and `round.pills.length` at the first step with `t >= 17`:
